# Authentication Types:

**Knowlegde Factors**: Password and answer to a security question. <br>
**Possession Factors**: Mobile Phone or Security Token <br>
**Inherence Factors**: Biometrics or pattern of behavior <br>

# Difference Between Authentication and Autherization:
`Authentication` is the process of verifying that a user is who they claim to be. `Autherization` involves verifying whether a user is allowed to do something.
